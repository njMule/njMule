njMule can be used from the keyboard. Press <kbd>F1</kbd>, or choose **⋯** → **Keyboard shortcuts**,
to see the main shortcuts in a small window; this page lists them all.

On macOS, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>, and <kbd>Option</kbd> for
<kbd>Alt</kbd>; njMule shows the keys as your system writes them (`⌘1` on macOS).

## Everywhere

| Keys | What they do |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | Opens **Transfers**. |
| <kbd>Ctrl</kbd>+<kbd>2</kbd> | Opens **Search**. |
| <kbd>Ctrl</kbd>+<kbd>3</kbd> | Opens **Shared Files**. |
| <kbd>Ctrl</kbd>+<kbd>4</kbd> | Opens **Messages**. |
| <kbd>Ctrl</kbd>+<kbd>5</kbd> | Opens **Network**, at the part you left. |
| <kbd>Ctrl</kbd>+<kbd>6</kbd> | Opens **Statistics**. |
| <kbd>Ctrl</kbd>+<kbd>7</kbd> | Opens **Options**. |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Opens the command palette: a place, a command, a search or eD2K links. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Folds the sidebar to its icons, or opens it again. |
| <kbd>F1</kbd> | Shows the keyboard shortcuts. |

The digits are those of the main keyboard, not of the numeric keypad.

### In the command palette

| Keys | What they do |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Choose a line. |
| <kbd>Enter</kbd> | Runs the line chosen. |
| <kbd>Esc</kbd> | Closes the palette. |

A letter typed while the command field of the top bar has the focus opens the palette with that
letter in it.

### In dialogs and menus

| Keys | What they do |
|---|---|
| <kbd>Enter</kbd> | The default answer of a dialog, the one ringed; in the questions about something risky, such as cancelling downloads, it is the safe answer. |
| <kbd>Esc</kbd> | Cancels or closes the dialog; closes the menu of the notification area. |

## Transfers

| Keys | Where | What they do |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | The screen | Shows the downloads and puts the cursor in **Filter the downloads**. |
| <kbd>Esc</kbd> | The filter | Empties it. |
| <kbd>Alt</kbd>+<kbd>Enter</kbd> | The screen | Shows the details of the download chosen. |
| <kbd>Enter</kbd> or a double click | A download | Opens it onto its sources, or closes it; opens the file of a completed download. |
| <kbd>→</kbd> | The downloads chosen | Opens them onto their sources. |
| <kbd>←</kbd> | The downloads chosen | Closes them. |
| <kbd>Delete</kbd> | The downloads chosen | Takes the completed ones off the list (their files stay) and asks before cancelling the others. |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | The downloads chosen | Copies their eD2K links. |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | The screen, outside its fields | Adds the downloads of the eD2K file links on the clipboard, in the category shown. |
| A double click | A name of **Source Names** | Takes the name over into the box to rename the download. |

On a Mac keyboard without a <kbd>Delete</kbd> key, press <kbd>Fn</kbd>+<kbd>⌫</kbd>.

## Search

| Keys | Where | What they do |
|---|---|---|
| <kbd>Enter</kbd> | **Search for** | Starts the search. |
| <kbd>+</kbd> | The results chosen | Shows the other names of a file found under several names. |
| <kbd>−</kbd> | The results chosen | Hides them again. |
| <kbd>Enter</kbd> or a double click | The results chosen | Downloads them. |
| <kbd>Esc</kbd> | The filter of the results | Empties it. |

## Shared Files

| Keys | Where | What they do |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | The list of files | Puts the cursor in **Filter shared files**. |
| <kbd>Esc</kbd> | The filter | Empties it. |

## Messages

| Keys | Where | What they do |
|---|---|---|
| <kbd>Enter</kbd> | The box to write | Sends the message. |
| <kbd>Enter</kbd> | **Letters in the picture** | Sends the answer to a CAPTCHA. |
| <kbd>Enter</kbd> | **IP or Address** | Opens the conversation with that address. |
| <kbd>Esc</kbd> | **Find a conversation** | Empties it. |

## Network

| Keys | Where | What they do |
|---|---|---|
| <kbd>Enter</kbd> or a double click | A server | Connects to it; <kbd>Enter</kbd> on the server you are on disconnects. |
| <kbd>Delete</kbd> | The servers chosen | Removes them from the list. |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | The servers chosen | Copies their server links. |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | The server list | Adds the servers of the server links on the clipboard. |
| <kbd>Esc</kbd> | **Filter servers** | Empties it. |
| <kbd>Enter</kbd> | **Update server.met from URL** | Downloads the list (**Update**). |
| <kbd>Enter</kbd> | **IP or Address** | Connects to that server (**Connect to address**). |
| <kbd>Enter</kbd> | **Nodes.dat from URL:** | Downloads the list (**Download**). |
| <kbd>Enter</kbd> | **From a client you know:** | Joins Kad through that node (**Bootstrap**). |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | The log, the server info | Copies the text chosen. |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | The log, the server info | Chooses all the text. |

## Options

| Keys | Where | What they do |
|---|---|---|
| <kbd>Esc</kbd> | **Find an option** | Empties it. |
| <kbd>↓</kbd> | **Find an option** | Moves to the list of pages. |
| <kbd>Enter</kbd> | **Find an option** | Moves to the first option found. |
