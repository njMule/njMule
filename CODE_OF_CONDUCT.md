# Code of Conduct

njMule adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and welcoming; disagree on ideas, never attack people.
- No harassment, discrimination, sexualised language or imagery, trolling or doxxing.
- Respect privacy: do not publish other people's personal data, including data from their
  file-sharing clients (user hashes, IP addresses, file lists).
- Assume good faith and help newcomers.

The rules apply to every project space (issues, pull requests, discussions) and to anyone
representing the project.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub
(<https://github.com/salvatore-coppola>). Reports are handled confidentially; the maintainer may
warn, temporarily ban or permanently ban participants who violate this code, following the
enforcement guidelines of the Contributor Covenant 2.1.
